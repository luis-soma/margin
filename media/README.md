# Margin films

Motion pieces for the case study and the website, rendered from HTML frame by frame.

- `margin-hero-2560.mp4` is the wide hero loop: a laptop with Figma open, a frame captured, a note added, saved to the archive.
- `margin-clip-*.mp4` are short loops, each about one part of Margin: the zoom slider, Reminder and Automatic, Hand off, the capture card, the sidebar, and Timeline and Themes.

The website's longer film lives in `site/media`.
